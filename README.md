# textkit

A tiny collection of Python string helper functions, built as a first-PR practice project.

## Functions

- `to_snake_case(text)` — convert `"Hello World"` to `"hello_world"`
- `to_title_case(text)` — convert `"hello world"` to `"Hello World"`
- `is_palindrome(text)` — check whether a string reads the same forwards and backwards

## Running tests

pytest
